# Запись пользовательского сценария

[Открыть видеозапись MP4](rehearsal.mp4) · Без звука, с русскими подписями. В кадре сайт offix и вымышленные сотрудники учебного офиса.

| Время | Что открыть при обсуждении |
|---|---|
| 0:00 | Вход в цели из списка текущих задач |
| 0:11 | Причина задержки, исполнитель и зависимая задача |
| 0:16 | Решение руководителя перенести сроки |
| 0:22 | Предпросмотр импорта с ошибочной единицей и повтором |
| 0:28 | Значение 34 минуты и источник в карточке цели |
| 0:33 | Повторный импорт того же замера |
| 0:37 | Сверка с отчётом |
| 0:42 | Назначение совещания и приглашение сотрудницы |
| 0:47 | Список встреч приглашённой сотрудницы, затем список коллеги без приглашения |

Запись сделана в Chromium на локальной сборке `3e4dbe3`, PGlite с миграцией `0016_meetings.sql`. Чтобы собрать ту же версию кода, на базу [45c0111](https://github.com/Ivan-Cupermush/FinTech/commit/45c0111) последовательно перенесите коммиты [713ed6a](https://github.com/Ivan-Cupermush/FinTech/commit/713ed6a), [f3b8b82](https://github.com/Ivan-Cupermush/FinTech/commit/f3b8b82), [3edeaa8](https://github.com/Ivan-Cupermush/FinTech/commit/3edeaa8) и [6ec6a7e](https://github.com/Ivan-Cupermush/FinTech/commit/6ec6a7e). Действия выполнены через интерфейс. При смене роли браузер открывал список сессии соответствующего вымышленного сотрудника. Перед отправкой жюри повторите показ на выбранном релизе.
