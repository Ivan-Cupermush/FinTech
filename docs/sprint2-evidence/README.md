## Доказательство импорта KPI

- [Предпросмотр](kpi-preview.png). Из трёх строк одна добавляется, одна содержит проценты вместо минут, одна повторяет первую.
- [Карточка после импорта](kpi-source.png). Последний замер — 34 минуты, источник «Из таблицы». При исходном значении 40 и цели 30 прогресс составляет 60%.
- [Синтетический CSV](https://github.com/Ivan-Cupermush/FinTech/blob/f3b8b82/docs/sprint2/kpi-import-control.csv) использует фиксированную дату серверного теста. Сквозной тест сначала подтверждает перенос срока, затем сверяет новый замер в карточке, тренде и отчёте. Повторная отправка не добавляет наблюдений.
- Снимки получены на локальном демо с теми же значениями и датой дня запуска.

[Совместный локальный прогон](integration.md) связывает назначение встреч, детали карты и импорт на одной сборке. В нём указаны SHA и действия для повторения.

[Проверка пустой карты и цели без срока](goal-edge-cases.md) описывает три состояния на сайте и в Expo.

[Проверка актуального main](release-f91d4fc.md) связывает браузерный прогон, CI и шаги проверки стенда после выкладки.
