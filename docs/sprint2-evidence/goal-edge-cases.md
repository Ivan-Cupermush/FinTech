# Пустая карта и цель без срока

Проверено на коммите `6ec6a7e` из [PR #27](https://github.com/Ivan-Cupermush/FinTech/pull/27). Локальный сервер с демонстрационными данными PGlite, Chromium, веб-сайт и веб-версия Expo в окне 390 × 844. Начните с демовхода проректора. Через API создайте черновик операционной цели с одним названием, без владельца и без срока. В обоих клиентах откройте прямую ссылку на её карточку.

| Состояние | Что увидел пользователь сайта и Expo |
|---|---|
| Новая цель без задач | «Плана пока нет», подпись «Без срока». Карта отсутствует. |
| Добавлена прямая задача без дат | У задачи и цели на карте есть подпись «без срока». Нажатие на цель открывает подробности с прочерком в поле срока. |
| Единственная прямая задача отменена | После повторного открытия снова видно «Плана пока нет». Пустая группа задач отсутствует. |

Между состояниями карточку полностью перезагружали. До исправления Expo при прямом входе запрашивал карту до чтения сохранённой сессии и получал HTTP 401. После исправления первый запрос карты во всех трёх состояниях отправился после восстановления сессии и получил HTTP 200. Доступ к чужим данным в этом сценарии не проверялся. Нативные сборки iOS и Android в прогоне не участвовали.
