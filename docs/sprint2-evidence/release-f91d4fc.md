# Проверка main для отдельного стенда sprint2

25 ноября 2026 г. · [Исходники f91d4fc](https://github.com/Ivan-Cupermush/FinTech/commit/f91d4fc080d25a416eb6dd8e6e579573fd84f6cd)

Локальная сборка сайта с Node.js 22, Chromium и новой демонстрационной базой PGlite. Проверка /health сообщила версию `f91d4fc`, миграцию `0016_meetings.sql` и наличие сборки сайта. GitHub завершил проверки check и mobile успешно.

## Что повторено

1. Открыть «Задачи» → «Цели» → «Сократить время обработки заявки студента». Выбрать «Автозаполнение формы заявки». Сверить исполнителя Дмитрия Орлова, причину задержки и зависимую задачу.
2. В разделе рисков подтвердить предлагаемый перенос сроков. В предпросмотре импорта подать дважды 34 минуты с датой прогона, а на другую дату — 30%. Убедиться, что добавляется одна строка. Карточка показывает 34 минуты и источник «Из таблицы». Повторный импорт блокирует добавление, отчёт показывает те же 34 минуты.
3. Назначить встречу, пригласить Анну и прочитать ближайшие встречи обычными сессиями приглашённой Анны и коллеги Дмитрия. Встреча есть в списке Анны, список Дмитрия её не содержит.

В Chromium открыли через прямую ссылку синтетическую цель без владельца и срока, добавили задачу без дат и отменили её. Сайт и веб-версия Expo показали пустое состояние, подписи «без срока» и снова пустое состояние соответственно. Во всех трёх случаях первый запрос карты в Expo был авторизован. Нативные приложения iOS и Android в этот прогон не входили. [Протокол проверки карты](goal-edge-cases.md)

Для повтора на отдельном локальном экземпляре в чистой копии `f91d4fc` выполнить `npm ci`, `npm run build`, затем `OFFIX_VERSION=f91d4fc PORT=4044 WEB_DIST_DIR="$PWD/web/dist" NODE_ENV=development npm run dev:demo`. Запуск создаёт новую демонстрационную базу. [Репетиционное видео предыдущей сборки](rehearsal.md)

## Сверка после выкладки Иваном

В /health отдельного sprint2 сверить SHA и миграцию, пройти чтение цели и открыть «Совещания» обеими ролями. Перенос, импорт и создание встречи в браузере повторять на выделенных демонстрационных записях. Для итогового комплекта зафиксировать ссылку, время и фактически проверенный SHA. При проверке из этой сессии отдельный sprint2 отдавал `f1b8477`. [Тестовый сайт sprint2](http://sprint2.147-45-43-34.sslip.io/login)
