# Навигация и граф в текущем стиле offix

Примеры для согласования Иваном и Ромой. Снимки сделаны из работающих веб-экранов offix и из веб-сборки мобильного приложения Expo на локальных демоданных. Предложенные перестановки показаны временно в браузере. Для сравнения использованы одни и те же данные и настройки темы. Приложения iOS и Android отдельно не запускались. На снимках мобильных задач выбран фильтр «Все», чтобы было видно содержание списка.

## UX-01 — меньше пунктов верхнего уровня

На сайте вместо 14 ссылок в меню владельца — шесть: **Задачи, Цели, KPI, Чаты, Совещания, Настройки**. Начальный экран — действующие «Задачи», открытые на фильтре «Мои». Уведомления доступны по колокольчику. В приложении пять вкладок в существующей стеклянной панели, настройки доступны по кнопке с ползунками справа от «Попросить». «Совещания» показаны как будущий пункт. Чаты, их счётчик и настройки видимости сохраняются.

| Куда перейти | Функции |
|---|---|
| Задачи | «Мои», командный список, календарь, вход в «Мои заметки». Ближайшие действия из «Пульса» |
| Цели | Сводка по целям из «Пульса», материалы конкретной цели и ссылка на общую базу знаний |
| KPI | Существующий «Эффект», отчёт и продажи для ролей с доступом к модулю |
| Чаты | Текущий вход и интерфейс |
| Совещания | Назначение и архив встреч после реализации модуля |
| Настройки | Профиль, команда и структура, администрирование компании по действующим правам |
| Уведомления | Колокольчик, счётчик непрочитанных и действующий экран уведомлений |

## UX-02 — граф ближе к названию цели

На сайте граф идёт сразу после заголовка и KPI, блок рисков — сразу после графа. В приложении дорожная карта поднимается сразу под карточку цели. Выбранная задача выделяет входящие и исходящие зависимости, остальные линии приглушаются. В демопримере включена цепочка «Автозаполнение формы заявки → Пилот автопроверки → цель». Связи, даты, подписи, легенда и оформление графа исходные.

После согласования стоит проверить короткие и длинные подписи, цели с несколькими пересекающимися цепочками, доступ с клавиатуры, даты вне видимой части графа, светлую и тёмную темы. Перенесённые функции должны остаться доступны с прежними правами. Существующие URL сохраняются.
