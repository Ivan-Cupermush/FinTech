## Маршрут

Старт после входа — «Задачи». Два перехода: **Цели → Сократить время обработки заявки студента**. На открытой карточке прокрутите до «Риски по цели» под графом. В сценарии проверяем, может ли человек объяснить, что задерживает работу, и назвать ответственного. Формулировка для участника: «Найдите, из-за чего задерживается цель по обработке заявок, и назовите коллегу, который может помочь». Маршрут заранее не подсказываем.

| Роль | Результат автоматического прогона | Материалы |
|---|---|---|
| Руководитель учебного офиса | Видит причину и исполнителя. Доступен просмотр предложенного переноса сроков | [Снимок](manager-risks.png) · [Видео](manager.webm) |
| Методист учебного офиса | Видит ту же причину и исполнителя. Действие переноса отсутствует | [Снимок](methodist-risks.png) · [Видео](methodist.webm) |

В демо заблокировано «Автозаполнение формы заявки». Причина — нет доступа к справочнику подразделений. Система показывает исполнителя Дмитрия Орлова и одну ожидающую задачу. Изменения сроков и записей в ходе прогона не выполнялись. Видео начинаются после входа.

## Замер с участниками

Два браузерных прогона подтверждают воспроизводимость сценария. Время человека, подсказки и ошибочные переходы ещё не измерены. Для исходного замера привлечь методиста и руководителя отдельно.
