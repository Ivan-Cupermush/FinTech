# Проверка черновика поручения из совещания

Проведите две отдельные сессии по 7–10 минут с методистом и руководителем. Покажите пример на бумаге или в документе. На действующем тестовом сайте уже можно назначить встречу и открыть список.

## Случай для участника

На сохранённом совещании «Пилот обработки заявок» руководитель согласовал: «Анна до 30 ноября проверит десять вымышленных заявок и перечислит ошибки». Дмитрий сказал: «Потом можно посмотреть, поможет ли новый шаблон». Покажите участнику текст без подсветки. Спросите, что он перенесёт в задачи и кто должен это подтвердить.

После ответа покажите заполненный черновик.

| Поле | Значение |
|---|---|
| Название | Проверить десять заявок и перечислить ошибки |
| Ответственная | Анна, методист |
| Срок | 30 ноября 2026 |
| Исходная встреча | Пилот обработки заявок |
| Действие | Изменить поля, сохранить черновик или подтвердить создание задачи |

Попросите исправить срок на 1 декабря и подтвердить создание. Покажите повторное открытие того же поручения с действием «Открыть задачу». Спросите, понятно ли, что произошло и как вернуться к источнику. Затем предложите случай без назначенного исполнителя: «Кто-то из офиса должен проверить ещё пять заявок». Попросите показать, что человек сделал бы с таким черновиком.

## Что записывает ведущий

| Проверка | Что считается успешным |
|---|---|
| Отбор договорённостей | Участник выбирает подтверждённое поручение Анны и оставляет предложение Дмитрия вне списка задач |
| Редактирование и подтверждение | Участник меняет дату и понимает, в какой момент задача появится в рабочем списке |
| Источник | Участник находит встречу или понимает, почему индивидуальный доступ к ней отсутствует |
| Повтор | Участник открывает уже созданную задачу из той же записи |
| Неясный исполнитель | Участник оставляет черновик для уточнения или сам выбирает ответственного |
| Полномочия | Ведущий узнаёт, кто в подразделении может подтверждать поручения и нужна ли делегация |

Для каждой попытки зафиксируйте роль, время, подсказки, ошибки и то, как участник описал результат своими словами. Итоги занесите в бланк из соседнего раздела. Коды участников используйте те же, если они уже участвовали в интервью. [Сценарий интервью и бланк](README.md)

## Критерии для реализации после проверки

- Черновик доступен участникам встречи с подходящими правами. Право подтвердить и назначить ответственного проверяет сервер по правилам создания задачи. Подтверждение переводит черновик в созданную задачу одной транзакцией. Параллельное подтверждение из двух клиентов возвращает ту же задачу. Ключ повторного подтверждения связан с ID черновика. Разные поручения из одной встречи могут стать разными задачами.
- Встреча остаётся источником черновика. Через карточку задачи сведения о встрече видят пользователи с доступом к ней. В тестах проверить организатора, приглашённого, постороннего сотрудника и другую организацию.
- Сохраняются явно заданные ответственный и срок. Когда из текста их нельзя вывести однозначно, поля остаются пустыми до решения человека. При временном сбое пользователь может повторить подтверждение и продолжить с заполненными полями.
- Для первого сравнения ведущий готовит образец текста вручную. Обработка записи и автоматическое извлечение поручений требуют отдельных проверок качества и согласования обработки данных.
