# Как провести два интервью в учебном офисе

Комплект для Ромы и второго ведущего. Пригласите отдельно методиста, который обрабатывает заявки, и руководителя, который согласует задержки. Для каждого запланируйте 15–20 минут. [Скачать пустой бланк Excel](fieldwork.xlsx)

## До звонка

Сделайте рабочую копию бланка в согласованной закрытой папке. В GitHub лежит только пустой шаблон. Скажите участнику, зачем нужны заметки, кто увидит результат, и что любой вопрос можно пропустить. Для этих двух бесед достаточно заметок. Используйте коды участников и широкие категории должностей. Записывайте пример своими словами, опускайте данные студента, коллег и самой заявки. Если участник показывает рабочую систему, попросите заранее скрыть персональные данные.

Подготовьте демовход нужной роли, откройте «Задачи», проверьте версию стенда через /health. В исходном сценарии используйте цель по обработке заявок. Для повтора подготовьте другую цель с сопоставимыми числом переходов, ветвлением, видимостью причины и исполнителя. До сеанса ведущий проходит оба варианта и записывает правильные ответы для сверки. [Исходная версия и контрольный ответ](../sprint2-baseline/README.md)

## Первые пять минут — наблюдение

Прочитайте одну фразу: «Найдите, из-за чего задерживается цель по обработке заявок, и назовите коллегу, который может помочь». Запустите таймер после чтения. Закончите при первом верном ответе на обе части, отказе участника или через три минуты. Если человек просит помочь, отметьте момент и запишите подсказку дословно. Ответ с подсказкой отмечайте отдельно. В конце попросите показать, где на экране человек нашёл ответ.

На листе «Прогоны» один ряд соответствует одной попытке. Считайте открытие раздела, другой карточки или узла карты переходом. Прокрутку исключите. Ошибочным считайте переход, после которого участник вернулся, потому что искал в другом месте. Отметьте обе части ответа и фактическое время даже при остановке. Для сравнения зафиксируйте роль, устройство, версию, вариант задания и предыдущий опыт. При повторе сохраните код участника. Если готовите два равноценных примера A и B, поменяйте их порядок для второго участника. Покажите результаты каждой пары и количество завершивших самостоятельно. Выборка из двух человек помогает разобрать затруднения, а оценка частоты для всей организации потребует более широкой выборки.

## Следующие десять минут — последняя реальная заявка

| Спросите | Куда записать |
|---|---|
| Вспомните последний случай, когда срок заявки оказался под вопросом. Что произошло сначала? Кто и по каким данным принял решение? | «Интервью», один ряд на беседу. Укажите дату, роль, шаг процесса и фактическое действие. |
| Что пришлось открыть или уточнить? Какие разделы вы действительно использовали за последнюю рабочую неделю? Сколько раз и примерно сколько минут активно работали в каждом? | «Использование», отдельный ряд для каждого названного раздела. Если человек затрудняется оценить, оставьте число пустым. |
| Сколько минут человек работал над случаем? Сколько затем ждали ответа? Где можно сверить эти цифры и число операций за последний полный месяц? | «Исходные данные», у ожидания и активного труда разные строки и единицы. Отмечайте источник каждой величины. |
| Когда действующий процесс уже удобен? Что лишнее в нашем предположении о проблеме? | «Наблюдения», один ряд на вывод, включая наблюдение против гипотезы. Запишите, какое решение оно изменит и как его проверить. |
| Вспомните последнее поручение после совещания. Кто согласовал исполнителя и срок? Как поняли, что задача уже создана? | При реальном примере отметьте потребность в черновике и этап подтверждения. Если такого случая не было, зафиксируйте это. |

Методиста попросите восстановить собственные действия по шагам. У руководителя уточните, когда требовалось именно его решение и где он видел результат. В конце прочтите одно предложение с основным выводом и дайте собеседнику его поправить.

## Что передать Ивану

На листе «Исходные данные» фиксируйте один показатель на строку с периодом, единицей, типом источника и охватом. Для числа заявок нужен период, для времени — минуты активного труда на одну операцию, для стоимости часа — агрегированная ставка от ответственного подразделения. Ставки конкретных сотрудников в бланк не вносите. Время выполнения задания на демостенде храните только в «Прогонах». Измерение экономии на реальном процессе требует сопоставимого замера до и после. Долю внедрения помечайте допущением до появления данных.

Передайте Ивану согласованные агрегаты и происхождение каждой цифры. При пересечении выборок анкеты и интервью укажите только те пересечения, которые известны без сопоставления анонимных ответов. Исследовательскую беседу считайте один раз, даже если в ней было несколько наблюдений и замер интерфейса. В общем журнале публикуйте обобщённый вывод, решение и статус проверки. Ссылки на исходные заметки выдавайте по согласованному доступу. [Короткая анонимная анкета](../product-review/SURVEY.md)

[Проверка черновика поручения из совещания](meeting-draft.md) использует короткий вымышленный пример для тех же двух ролей.

[Контрольные тексты для помощника](meeting-text-checks.md) проверяют тезисы, решения и черновики на вымышленных встречах.
