## Условия реализации после согласования

- Храним порядок стабильных ID для пары пользователь/организация. Отсутствие предпочтений означает исходное меню. Пустой список означает, что пользователь снял все закрепления.
- Список пользователя пересекается с существующими правами, модулями и маршрутами клиента. Недоступный в Expo экран не превращается в нерабочую ссылку. Каталог и выбранный набор не расширяют серверные права.
- Перестановка доступна кнопками «Выше» и «Ниже», сброс возвращает исходный набор. При ошибке сохранения остаётся предыдущий сохранённый порядок и виден результат ошибки.
- На общем демовходе состояние ограничено сессией. Для проверки сохранения между входами берём раздельные синтетические профили.
- Перед PR проверяем двух пользователей одной компании, общий демовход, пустой и исходный наборы, выключение модуля после закрепления, клавиатуру, узкое окно и отказ сохранения.
