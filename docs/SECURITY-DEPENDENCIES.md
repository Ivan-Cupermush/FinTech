# Проверка производственных npm-зависимостей

25.11.2026 проверен корневой `package-lock.json` командой
`npm audit --omit=dev --audit-level=high`. До обновления npm сообщил о двух пакетах
с уровнем high: `body-parser` 2.3.0 и `sharp` 0.34.5. После обновления lock-файла
до `body-parser` 2.4.0 и `sharp` 0.35.5 повторный аудит не сообщил об уязвимостях.
Результат зависит от базы npm на момент проверки и не гарантирует отсутствие ошибок.

- [GHSA-27r3-jxmh-p828](https://github.com/advisories/GHSA-27r3-jxmh-p828):
  обработка сжатого тела запроса. В сервере используется `express.json`, поэтому
  обработчик запросов присутствует; конкретный путь эксплуатации отдельно не
  воспроизводился. Версия 2.4.0 исправляет указанное предупреждение.
- [GHSA-f88m-g3jw-g9cj](https://github.com/advisories/GHSA-f88m-g3jw-g9cj),
  [GHSA-rgj7-g3m4-5g8c](https://github.com/advisories/GHSA-rgj7-g3m4-5g8c),
  [GHSA-wq5f-xc86-pv6w](https://github.com/advisories/GHSA-wq5f-xc86-pv6w):
  уязвимости зависимостей обработки изображений. Сервер вызывает sharp для загруженных
  фотографий; применимость каждого формата и платформы отдельно не подтверждена.
  В 0.35.5 исправлены перечисленные предупреждения для поставляемых готовых бинарных
  библиотек. При использовании глобально установленных библиотек их версии нужно
  проверять отдельно согласно описаниям sharp.

Аудит `--omit=dev` не охватывает инструменты разработки, отдельный lock-файл мобильного
приложения, нативный kusok, системные пакеты и развернутые копии. Эта проверка не
является SBOM или подписью релиза; они остаются отдельными задачами плана. Обновление
исходников и lock-файла не означает, что какой-либо стенд обновлён.
